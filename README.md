# 🚀 Estudos de Web API em C# (.NET)

Este repositório reúne exercícios, pequenos projetos e conceitos praticados durante a faculdade de Engenharia de Software e em estudos autônomos utilizando **C#** e **ASP.NET Core Web API**.

---

## 🛠️ Tecnologias e Ferramentas
- **Linguagem:** C# (.NET 8+)
- **Framework:** ASP.NET Core Web API
- **Conceitos:** Programação Orientada a Objetos (POO), Encapsulamento, Injeção de Dependência, REST API.
- **IDE / Editor:** Visual Studio / VS Code

---

## 📂 Estrutura de Exercícios

| Projeto / Módulo | Descrição / Conceitos Abordados |
| :--- | :--- |
| **`WebApiExemplosPOO`** | Introdução à integração de POO com Web API. Demonstração de encapsulamento, auto-propriedades, modelagem de entidades (`ContaCorrente`, `Funcionario`) e criação de Controllers (`ExemploEncapsulamentoContaCorrenteController`, `FuncionarioController`). |
